# Female Tamil reference clip

Place a clean reference recording at:

`reference/female-reference.wav`

Recommended input:
- 15–30 seconds
- one female Tamil speaker only
- dry/clean recording, minimal room echo
- no music, effects, or overlapping voices
- normal speaking voice, not whispering
- preferably 16 kHz or higher WAV
- use only audio you have permission to clone/use

The audition workflow will generate five conservative Tamil variants designed to minimize shakiness, garbling, noise, and robotic prosody.
